# Курьер JOB — демо сайта (лендинг)

## Как выложить на GitHub Pages
1. GitHub → репозиторий kuryer-site → Add file → Upload files.
2. Перетащите ВСЕ файлы из этой папки: index.html, style.css, geo.js, README.md, все city_*.html и папку lang целиком.
3. Внизу Commit changes. Через 1–3 минуты сайт обновится.
Проверка: https://cartoonxxx.github.io/kuryer-site/

## Структура
- index.html — главная с селектором городов
- city_*.html — лендинги городов: Москва, СПб, Казань, Саратов, Кызыл, Химки
- lang/ — языковые версии для Москвы и Химок: _uz.html, _ky.html, _tj.html
- geo.js — гео-баннер «вы в N — показать условия?», выбор запоминается в localStorage
- style.css — оформление (тёмная тема, жёлтый акцент)

## Перед боевым запуском
1. Замените «Курьер JOB» в footer и title на ваш бренд.
2. Проверьте ссылки анкет в city_*.html — сервисы иногда меняют адрес регистрации.
3. geo.js содержит список из 6 городов; при расширении добавляйте пары "ключ":"имя_файла".
4. Доходы пересчитывайте при смене акций — модель описана ниже.

## Модель доходов
- Пеший — база (Москва ~80 000 ₽).
- Электровело = ×1,8–2,5 от пешего (Москва 160–240 тыс.).
- Велосипед = ×1,3–1,6 от пешего.
- Авто: самый высокий тариф за заказ, но итог сопоставим с электровело; в растянутых городах может выходить вперёд.
