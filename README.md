# Курьерский центр — сборка v17

Выкладка на GitHub Pages:
1. Удалите старые файлы в репозитории.
2. Add file → Upload files → перетащите ВСЁ содержимое этой папки (index.html, папки moskva и saratov, spec.md, robots.txt, sitemap.xml). Файл _data.json не загружайте — это служебные данные генератора.
3. Убедитесь, что в корне репозитория есть файл .nojekyll (создайте пустой, если нет).
4. Commit → дождитесь зелёной галочки в Actions → откройте сайт.
