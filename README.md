# Порядок выкладки
1. Удалите в репозитории все старые файлы.
2. Add file → Upload files → перетащите: index.html, папки moskva/ и saratov/, spec.md, README.md.
3. Create new file → имя .nojekyll → Commit (если файла ещё нет).
4. Дождитесь зелёной галочки в Actions.
5. Проверьте: карточки сервисов, выбор города, переход на лендинг, калькулятор.
