# Сайт набора курьеров — демо v3

## Файлы (17 шт.)
- index.html — главная
- style.css, geo.js, .nojekyll — оформление и гео-подсказка
- city_moskva.html, city_spb.html, city_kazan.html, city_saratov.html, city_kyzyl.html, city_himki.html — страницы городов
- lang/uz, lang/ky, lang/tj — языковые версии для Москвы и Химок

## Публикация
1. В репозитории удалите ВСЕ старые файлы (в том числе selector.js — его больше нет).
2. Add file → Upload files → перетащите ВСЁ содержимое распакованной папки: файлы из корня И папку lang целиком (можно перетащить папку lang прямо в окно загрузки).
3. Commit changes. Дождитесь зелёной галочки во вкладке Actions.
4. Сайт: https://cartoonxxx.github.io/kuryer-site/

## Важно
- Все имена файлов строчными буквами и совпадают со ссылками — не переименовывайте.
- Ссылки на анкеты сервисов поставлены на официальные домены, но перед боевым запуском сверьте их вручную.
- Файл .nojekyll обязателен: без него GitHub прогоняет сайт через Jekyll и может ломать пути.
