ДЕМО-ПАКЕТ САЙТА «КУРЬЕРКА»
============================
Состав:
- index.html — главная: селектор города + гео-баннер
- city_*.html — страницы городов (6 штук для демо)
- style.css, selector.js, geo.js — оформление и логика
Гео-подсказка: определяет город по IP (сервис ipapi.co), показывает баннер
«Показать условия для вашего города?» — без автоперехода. Выбор города
запоминается в localStorage.
Как выложить: загрузить все файлы в корень любого хостинга (даже GitHub Pages).
Как расширять: добавить город в CITIES в geo.js и selector.js, создать
city_<имя>.html по шаблону существующей страницы. При переходе на полный
объём (65+ городов) страницы можно генерировать скриптом из общей таблицы —
обращайтесь, соберу генератор.
Ограничение демо: гео-словарь пока содержит только 6 демо-городов; при
расширении словарь дополняется на каждый новый город.
